Capturas de los temas de Oh My Posh (uno por tema: `<id>.svg`), generadas con
`scripts/make_prompt_images.py` usando `oh-my-posh config export image` y los datos de ejemplo del
sitio oficial (`--data-only`: no se lee nada de la PC). Cada SVG trae dentro un subconjunto de
Hack Nerd Font con solo los caracteres que usa. Temas © Jan De Dobbeleer, licencia MIT (ver LICENSE).
Si falta una imagen, la app dibuja una vista genérica.
